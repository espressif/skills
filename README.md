# Agent Skills

A collection of skills for AI coding agents to help develop solutions based on Espressif products.

Skills are stored in [Agent Skills](https://agentskills.io/) format.

## Installing skills

Install all the skills in this repository:

```shell
npx skills add espressif/skills
```

Install a specific skill:

```shell
npx skills add espressif/skills --skill skill-name
```
