# Contributing to espressif/skills

We appreciate contributions to espressif/skills in the form of issues and PRs.

## Third-party contributions

The repository is mainly intended for skills developed by Espressif employees. We encourage the community to create separate repositories for skills related to Espressif products.

That said, if you think there's a great ESP-related skill out there that deserves more visibility, please open an issue to tell us about it.

We welcome issue reports and PRs that fix mistakes in existing skills. Suggestions for new skills are welcome too — open an issue to discuss before sending a PR.

## Creating new skills

Please follow the [quickstart](https://agentskills.io/skill-creation/quickstart) and the [best practices](https://agentskills.io/skill-creation/best-practices) to create new skills.

## Adding new skills to this repository

Add the new skill under the `skills/` directory, commit, and open a merge request. Please include a link to an example session transcript demonstrating the skill's usage in the MR description.
